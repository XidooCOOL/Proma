# 多任务并行执行助手

## 功能

本 Skill 提供强大的多任务并行执行能力，可以让 AI Agent 同时处理多个不同类型的任务：

### 支持的任务类型

#### 1. 商品运营任务
- 商品上架（支持多平台）
- 订单处理
- 库存管理
- 价格调整

#### 2. 内容采集任务
- 小红书内容采集
- 竞品分析
- 价格监控
- 市场调研

## 使用方法

### 场景1：多商品多平台上架

```
请帮我上架这些商品：
1. 商品A（女装连衣裙，价格199）到抖音和拼多多
2. 商品B（运动鞋，价格299）到抖音、拼多多和淘宝
```

### 场景2：运营 + 采集并行

```
帮我上架这3个商品到抖音，同时去小红书采集女装爆款文案
```

### 场景3：批量处理

```
帮我处理今天所有的待发货订单，同时更新商品库存
```

## 工作原理

### 任务理解
当用户输入指令后，系统会：
1. **解析意图** - 识别用户的真实需求
2. **任务拆解** - 将复杂任务拆分为可执行的子任务
3. **任务分组** - 将任务按类型分组（运营任务、采集任务）
4. **并行执行** - 多个任务同时执行
5. **结果汇总** - 收集所有结果并生成报告

### 执行流程

```
用户指令
    ↓
意图解析
    ↓
┌─────────────────────────┬─────────────────────────┐
│  运营任务组            │  采集任务组            │
│  ├─ 任务1 (抖音)      │  ├─ 任务A (小红书)    │
│  ├─ 任务2 (拼多多)    │  └─ 任务B (竞品)      │
│  └─ 任务3 (淘宝)      │                        │
└─────────────────────────┴─────────────────────────┘
    ↓
并行执行
    ↓
结果汇总
    ↓
生成报告
```

## 任务模板

### 商品上架模板
```json
{
  "type": "operation",
  "action": "product-listing",
  "target": {
    "platform": "pinduoduo|douyin|taobao|jd",
    "store": "店铺名称"
```

## 注意事项

1. **任务数量限制**
   - 单次最多支持 100 个子任务
   - 建议单次任务控制在 20 个以内以获得最佳性能

2. **执行顺序**
   - 不同类型的任务会并行执行
   - 同类型任务会排队执行（避免资源竞争）

3. **错误处理**
   - 失败任务会自动重试（最多3次）
   - 关键错误会暂停后续任务并提示

4. **数据安全**
   - 所有数据都在本地处理
   - 登录信息保存在独立的浏览器 Profile 中
