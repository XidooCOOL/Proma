# 电商自动化操作指南

## 适用平台
- 拼多多商家后台
- 抖音电商罗盘
- 淘宝/天猫商家中心

## 核心功能

### 1. 商品上架流程
1. 检查浏览器 Profile 是否已经登录
2. 进入商品发布页面
3. 填写商品信息（标题、价格、库存、分类）
4. 上传商品图片
5. 提交发布
6. 截图保存确认

### 2. 订单处理流程
1. 进入订单管理页面
2. 查询待发货订单
3. 批量发货操作
4. 更新物流信息
5. 导出订单数据

### 3. 数据监控流程
1. 进入数据中心
2. 查看今日销售数据
3. 查看商品访客/转化数据
4. 生成数据报告

## 浏览器 Profile 管理
每个店铺使用独立的浏览器 Profile，存储路径：
- 主 Profile：`~/.proma/agent-workspaces/{工作区slug}/browser-profile/`
- 备份路径：`~/.proma/agent-workspaces/{工作区slug}/browser-profile-backup/`

## 注意事项
1. 操作前先检查是否已登录
2. 重要操作前先截图
3. 操作完成后记录日志
4. 如遇平台更新，暂停操作等待确认
