# 订单管理助手

## 功能
- 查询订单列表
- 批量发货处理
- 订单状态跟踪
- 退款/退货处理
- 异常订单处理

## 使用方法

### 查看今日新订单
```
帮我查看今天有哪些新订单
```

### 批量发货
```
帮我处理今天的新订单，批量发货
```

### 查询订单
```
帮我查询订单号 PDD123456789 的状态
```

## 执行流程

### 订单查询流程
1. 打开订单列表页面
2. 设置筛选条件（日期、状态）
3. 获取订单数据
4. 整理并展示

### 批量发货流程
1. 筛选待发货订单
2. 获取每个订单详情
3. 检查库存是否充足
4. 填写物流信息
5. 批量提交发货
6. 生成发货报告

### 退款处理流程
1. 查看退款申请列表
2. 查看退款原因
3. 审核退款申请
4. 执行退款操作

## 平台特定功能

### 拼多多
- 待发货订单处理
- 批量发货支持
- 物流信息填写
- 退款审核

### 抖音
- 订单状态同步
- 物流跟踪
- 售后处理

## 注意事项
- 批量操作需要设置合理的间隔时间
- 遇到异常订单需要标记并暂停
- 物流单号需要核对格式
